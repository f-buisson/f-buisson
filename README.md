## What I build

I build operational software with a simple principle: start from a real field problem, keep the workflow understandable, and automate repetitive work without taking control away from the person using it.

### Open source

#### [OpenRetailSchema](https://github.com/f-buisson/OpenRetailSchema)
**An open interoperability layer for retail and POS data.**

OpenRetailSchema aims to provide a common, vendor-neutral model for retail data so applications can integrate with multiple POS systems without rebuilding the same mapping layer every time.

Current direction:
- common schemas for stores, employees, products, sales, prices, inventory, payments, taxes and time-based metrics;
- connector architecture for POS platforms and generic CSV imports;
- raw payload preservation alongside normalized data;
- reusable foundations for analytics, workforce planning and retail automation;
- contributor-friendly documentation and public extension points.

The project is designed to be useful independently while also serving as a shared integration layer for F-Buisson products.

## Principles

- **Start from the field** — solve a concrete operational problem before adding features.
- **Keep systems understandable** — outputs and decisions should be explainable.
- **Keep humans in control** — automate repetitive work without removing managerial judgment.
- **Minimize training** — software should be usable with clear workflows and contextual guidance.
- **Build reusable foundations** — shared infrastructure should reduce duplicated integration work across products.

## Français

F-Buisson développe des logiciels métier orientés terrain, principalement pour le commerce et les opérations quotidiennes.

### Projet open source principal

**[OpenRetailSchema](https://github.com/f-buisson/OpenRetailSchema)** vise à créer une couche d'interopérabilité commune entre logiciels de caisse / POS et applications métier. L'objectif est de normaliser les données de vente, produits, prix, stocks, employés, paiements, taxes et métriques temporelles afin qu'une intégration réalisée une fois puisse être réutilisée par plusieurs logiciels.

### Produits

- **Alertarif** — surveillance des prix, promotions, marges et qualité des données.
- **PlanCaisse** — planification des équipes caisse à partir des besoins réels et des contraintes opérationnelles.
- **PlanFlux** — suivi des renforts réellement effectués entre services.

Les dépôts publics utilisent l'anglais comme langue principale et le français comme langue secondaire. Les applications commerciales restent développées dans des dépôts privés.
